# Migrer progressivement

Votre projet fil rouge vers php

1. Committer les modidifications en cours
2. Créer une branche, par exemple `php`
3. Renommer les fichiers `.html` en `.php`
4. Utiliser `include_once` pour inclure les parties communes (header, footer, etc.)
5. Modéliser les données avec looping MCD et MLD
6. Créer votre base de données et les tables correspondantes (script SQL de looping à peaufiner)
7. Implémenter la logique de connexion et de gestion des utilisateurs
    - Ajouter des fonctionnalités CRUD 
8. Implémenter les fonctionnalités d'affichage pour les articles de blog
9. ...
